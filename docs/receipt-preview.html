6 receipt variants:

1. Cash — Basic cash payment
2. QRIS — Basic QRIS payment (exact amount)
3. Cash + PPN — Cash with 11% tax, shows Subtotal + PPN + TOTAL
4. QRIS + PPN — QRIS with 11% tax
5. QRIS + Admin Fee — QRIS with admin fee charged to customer
6. QRIS + PPN + Fee — QRIS with both tax and admin fee

When tax/fees are active, the totals section shows:
Subtotal → PPN 11% → Admin Fee → bold TOTAL

When no tax/fees, only bold TOTAL is shown (no subtotal line).
